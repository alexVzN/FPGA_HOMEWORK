# Домашнє завдання до Лекції 15
Створити ІР ковзаючого максимуму.
В каталозі HW є заготовка для ДЗ у вигляді с++ файлів.  
Дописати або переписати функцію на с++, яка бере 64 числа і для кожного числа знаходить найбільше з останніх 8 чисел (разом із поточним).
Вхід: масив із 64 цілих чисел. Вихід: масив із 64 цілих чисел.
Правило: out[n] = найбільше з in[n-7] ... in[n]. Для перших семи відліків береться максимум із наявних. Звичайно, якщо n<7, то наявні від 0 до n.
Функція C++ moving_max(int in[64], int out[64]), масиви фіксованого розміру, без malloc, без зашитих адрес. Кожен елемент in читається один раз.
С++ тестбенч - окремий файл, що порівнює функцію з еталоном (прямий перебір за правилом вище), перевіряє мінімум п'ять вхідних векторів, повертає 0 при успіху і 1 при помилці.
Зібрати дві версії функції.
-  без директив, з вимкненим автоконвеєруванням;
-  з #pragma HLS PIPELINE II=1.
1) У Vitis HLS створити компонент із цими файлами.
2) Створити тестбенч на С.
3) Запустити C Simulation.
4) Запустити C Synthesis і записати цифри: скільки тактів, скільки ресурсів: DSP, FF, LUT.
5) Додати в код рядок #pragma HLS PIPELINE II=1, знову запустити C Synthesis і записати ті самі цифри.
6) Запустити Co-simulation і Package.
7) Створити тестбенч на verilog.
8) Запустити симуляцію в Vivado.
9) Зробити скріншот симуляції.

   Для швидшої перевірки, закидуйте проекти Vitis i Vivado на git.
